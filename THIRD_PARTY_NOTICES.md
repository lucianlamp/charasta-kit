# 第三者の部品と素材

きゃらすたに同梱している第三者の部品と素材の一覧です。きゃらすた本体の条件は `LICENSE.md` で、ここに書いた物にはそれぞれの条件が優先して適用されます。

## 1. 同梱している物

### JavaScript の部品(vendor/)

| 部品 | ライセンス | ファイル |
| --- | --- | --- |
| three.js(本体と examples の部品: GLTFLoader、OrbitControls、BufferGeometryUtils、SkeletonUtils) | MIT | vendor/three.module.js ほか。条件は vendor/THREE-LICENSE.txt |
| @pixiv/three-vrm | MIT | vendor/three-vrm.module.js。条件は vendor/three-vrm-LICENSE.txt |
| @pixiv/three-vrm-animation | MIT | vendor/three-vrm-animation.module.js。条件は vendor/three-vrm-animation-LICENSE.txt |
| meshoptimizer(simplifier) | MIT | vendor/meshopt_simplifier.module.js。条件は vendor/meshoptimizer-LICENSE.txt |
| HyperFrames のプレビュー用ランタイム 0.8.33 | Apache-2.0 | public/vendor/hyperframes-player.global.js、public/vendor/hyperframe.runtime.iife.js |

### フォント

| フォント | ライセンス | 場所 |
| --- | --- | --- |
| Noto Sans JP、Noto Serif JP(ショートの字幕) | SIL Open Font License 1.1 | public/fonts/ |
| Zen Maru Gothic(ショートの字幕) | SIL Open Font License 1.1 | public/fonts/ |
| Anton、Dela Gothic One、Noto Sans JP(グラフィック MV) | SIL Open Font License 1.1 | stage-studio/assets/fonts/ |

### 画像と音

- `stage-studio/assets/` の下の絵(ステージのテクスチャ、小道具、サムネイル)は、作者が OpenAI の image_gen で生成した画像です。第三者の素材集、写真、有料アセットは使っていません。
- `assets/sfx/*.wav`(効果音)と `assets/bgm/*.m4a`(BGM)は、作者が numpy で合成した音です(`tools/make_sfx.py`、`tools/make_bgm.py`)。外部の素材を使っていません。
- `test/fixtures/sample.vrma` は、テスト用に `test/fixtures/make-vrma.mjs` で作った動きです。

### npm の依存(同梱せず、`npm install` で入る)

- Playwright 1.63.0(Microsoft、Apache-2.0)。ライセンスの文は `npm install` のあと `node_modules/playwright/LICENSE` に入ります。

### Python の依存(同梱せず、`pip install -r requirements.txt` で入る)

- NumPy(BSD-3-Clause)、SciPy(BSD-3-Clause)、Pillow(MIT-CMU 系の HPND)、scikit-image(BSD-3-Clause)。各パッケージの配布物にライセンスの文が入っています。

## 2. 同梱しないが、使うときに入れる物(任意の機能)

次の物はこのキットに含まれません。使う人が自分で入れ、それぞれの条件に従います。入れなければ、その機能は画面で使えない状態になります。

| 機能 | 入れる物 | 条件 |
| --- | --- | --- |
| 歩き・走りなどのモーション生成 | MotionBricks(NVIDIA) | モデルは NVIDIA Open Model Agreement。生成の文脈と目標に使う見本の動きは NVIDIA Sample Data Evaluation License(評価・テスト用、配布不可) |
| 動画からのモーション生成 | vrma-pipeline(MediaPipe) | 配布元の条件に従う(確認してから使う) |
| モーションのパック | VRoid Project VRMA Motion Pack | 同梱しない。権利者はピクシブ株式会社。条件は配布元に従う |
| 3D の描画、表情づくり | Blender(GPL) | 同梱しない |
| 動画の書き出し | ffmpeg | 同梱しない。ビルドごとの条件に従う |
| 声の生成 | VOICEVOX Engine ほか | 同梱しない。VOICEVOX は音声ライブラリごとの利用規約とクレジット表記に従う |
| ショートの文字と演出 | HyperFrames の CLI | 同梱しない(Apache-2.0)。プレビュー用のランタイムだけ上の表のとおり同梱している |

`lib/model-licenses.json` に、モーション生成で作ったモーションへ記録する条件の文があります。
