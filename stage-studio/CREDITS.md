# クレジット

## テクスチャと小道具の絵

assets/ の下の絵(各ステージのテクスチャ、assets/props、assets/thumbs)は、作者が Codex 経由で OpenAI の image_gen を使って生成した。生成に使った指示文は assets/*/prompts に残してある。
第三者の素材集、写真、有料アセットは使っていない。

## 字体

assets/fonts の 3 つの字体はいずれも SIL Open Font License 1.1。出どころと条件は assets/fonts/LICENSES.md を見る。

- Anton
- Dela Gothic One
- Noto Sans JP

assets/props/letter.png の本文は、作者の Windows にあるフォントで書いた画像として同梱している。字体のファイルは同梱していない。
