# VRoid 形式の顔(自前の部品と Fcl の 57 キー)

きゃらくる(Tripo Studio)で作った頭の形を残したまま、VRoid と同じ構成の顔を新しく作ります。`Face` メッシュ 1 つに、肌、白目、虹彩、ハイライト、まつ毛、眉と二重の線、口の中（歯と舌）を部品として入れ、`Fcl_` の 57 キーを持たせます。目線は目の骨 2 本（`lookAt: bone`）で、プリセット 14 個は 1 キーずつ割り当てます。Blender は使わず、GLB へ直接書き足すので、Body、Hair、揺れものは元のままです。

この方式は標準ではなく予備。通常の頭身はきゃらくるの表情工程と `kit_fcl.py` で作り、ちび体型は顔画像の方式で作る。キットの表情でうまくいかないときにだけ、ここの自前の部品を使う。使い分けは `docs/expression-studio.md` の「表情の方式の使い分け」。

作る道具はきゃらすたの `studio/vroid/face_own/` にある。後頭部の内張り `build_liner.py` も同じフォルダにある。組み立てのあとは `docs/vroid-format.md` の変換と検査を通す。

## 用意するもの

- 材料の VRM: 髪と Body と揺れものが済んだもの。後頭部の内張り `Head_liner` は無くても、組み立てで足します。
- 中立の絵 `neutral.png`: 髪のない、目を開いた正面の顔。作り方は `docs/face-atlas.md` の「顔の絵」と同じです。キャラ全体の絵から表情を作る規則も同じです。
- 部品の絵 5 枚（下）。
- キャラの値の JSON。既定の値 `studio/vroid/face_own/defaults.json` に重ねます。

## 部品の絵 5 枚

`codex-image-gen` スキル(Codex の image_gen)で、`neutral.png` を入力に作ります。**描いた絵はそのまま使います。** コードで線を抜き出したり、色で切り抜いたり、描き直したりしません。切り抜きが足りなければ image_gen に描き直させます。透過の絵は本物のアルファで受け取り、角のアルファが 0 であることを確かめます。

| ファイル | 頼むこと |
|---|---|
| `skin.png` | 目、まつ毛、二重の線、眉を消して素肌にする。頬の赤み、鼻、口の線、輪郭、キャンバスはそのまま |
| `lash.png` | 上のまつ毛の帯と下まつ毛だけを透過で残す。位置と大きさを動かさない。開口の中は透明 |
| `brow.png` | 眉と二重の線だけを透過で残す。位置と大きさを動かさない |
| `iris.png` | 虹彩だけを、まぶたで隠れた所まで補って完全な楕円で、左右 2 つ並べて透過で描く。ハイライトは描かない。1536x1024 |
| `high.png` | 虹彩の上の白いハイライトだけを透過で残す。位置と大きさを動かさない |

`iris.png` 以外は `neutral.png` と同じキャンバスです。少し大きさが変わって返ってくることがあるので（1391x1114 が 1402x1122 になった）、組み立ては縦横の比で読み替えます。絵を並べて、ずれが数画素以内か確かめます。

## キャラの値

キャラの JSON に必ず書く項目です。場所はキャラの作業フォルダに置き、スキルの中には置きません。

| 項目 | 中身 |
|---|---|
| `source_vrm`, `neutral`, `images`, `work` | 材料の VRM、中立の絵、部品の絵のフォルダ、作業フォルダ |
| `head_mesh`, `skin_material`, `remove_nodes` | 頭のノード名、肌の元にする材質、顔の絵のノード（外す） |
| `surface` | `center`（頭の中心）、`grid`（正面の高さの表の範囲 `[x0,x1,y0,y1]`）、`ear_u`（耳を落とす方位角）、`jaw`（顎の合わせ込み。不要なら `null`） |
| `tex_box`, `forehead` | 肌のテクスチャの範囲 `[x0,x1,y0,y1]`、肌の色を取る額の箱 `[cx,半幅,y0,y1]` |
| `align` | 下の 2 つのどちらか |
| `eye_xf` | 目を広げる倍率 `k` と外への移動 `dx`（mm）。元絵の目の大きさに合わせる |
| `iris` | 中心 `cx.L`, `cx.R`, `cy`（m）と半径 `rx`, `ry`（mm） |
| `mouth` | 口の中心 `xm`, `ym`、半分の幅 `W0`、切れ目の domain の高さ `h0`（m） |
| `paint` | 絵を使う楕円 `[cx,cy,rx,ry]`。頬、鼻、口だけ。輪郭や耳が入ると肌に斑ができる |
| `white_box`, `white_rgb`, `white_shade` | 白目の範囲と色、上まぶたの影の透過の絵（任意） |
| `skin_factor`, `skin_shade` | 肌の色の倍率。肩の肌に合わせて測る。2 つを同じ値にすると肌に陰が付かない |

`align` は 2 つあります。

- `mode: "direct"`: 絵の画素と正面の対応が分かっているとき。`x0`, `y0`（絵の左上の x, y）、`dxdpx`（1 画素の長さ）と、目の開口を緑で塗った絵 `eye_mask`（これも image_gen で作る）を渡します。
- `mode: "atlas"`: 材料の VRM が顔画像の方式で作られているとき。アトラスの中立の区画を正面に戻して絵を重ね、穴を目の開口にします。`material`, `size`, `rect`, `eye_box`, `ink_window`, `scale` を渡します。

表情の量は `defaults.json` の `eye`, `brow`, `mouth_shapes` です。キャラの表情の絵を見て、キャラの JSON で上書きします。単位は mm です。

## 手順

```bash
SK=studio/vroid/face_own
python $SK/own.py merge $SK/defaults.json <キャラ>.json params.json
python $SK/own.py place params.json             # <work>/place.png を作る
python $SK/own.py build params.json out.vrm
python $SK/verify.py out.vrm <材料.vrm>
```

### 目と口の位置を確かめる

`place.png` を見ます。緑が読んだ目の開口、黄が広げたあとの開口、水色が虹彩、青が口の線です。

- 緑が絵の目の輪郭に沿っているか。ずれていれば緑の塗りを image_gen に塗り直させる（コードで削らない）。
- 虹彩が絵の虹彩に重なり、下の端が開口の下の縁に届いているか。上は開口より上へはみ出してよい。
- 口の線が絵の口に重なっているか。

### 組み立ての確かめ

`verify.py` で、Body と Hair の中身、残した画像、揺れもの、既存のノードが元と同じで、キーの名前が 57 個すべて公式と同じであることを見ます。`Fcl_ALL_Neutral`、`Fcl_EYE_Natural`、`Fcl_MTH_Neutral` の 3 つは公式でも変形量 0 です。

形式の検査は npm の `gltf-validator`（Khronos 公式）を作業用フォルダに入れて行い、エラー 0 を確かめます。`vrm-validator`（第三者のフォーク）は VRM の項目も見ます。

### 見た目の確かめ

きゃらすたへ版として取り込み（`node scripts/import-version.mjs --char <キャラ> --id <版> --label "…" --note "…" --src out.vrm`）、きゃらすたの画面 `#face/<キャラ>/<版>` で確かめます。本番の保管場所へは、テスト用の保管場所で見た目を確かめてから入れます。

画面でプリセット 14 個、`Fcl_` のキーのスライダー、視線、版どうしの比較を見て、確かめの撮影を 3 種類ボタンで撮ります。

| 撮影 | 中身 |
|---|---|
| 格子と表情 | `yaw -45/0/25/45/65/90 × pitch 25/0/-25` の格子、全プリセット、口の形、視線、表情と視線 |
| キー別 | 57 キーを 1 つずつと、開いた口の歯のキーの組み合わせ |
| モーション | モーション中の顔の寄りと、髪が顔の面より内側へ入る頂点の数 |

見ること:

- 肌と肩の肌の色が同じか。`yaw -45/0/25/45/65/90 × pitch 25/0/-25` のどれでも破綻がないか。
- 閉じた目で虹彩が抜けないか（0.1 刻みの途中も）。抜けるなら `ball.lid_clear` を上げる。
- 口の中の部品が閉じた口の下へ透けないか。斜めと下から開いた口の中が空でないか。
- 頬の外で動かしたとき、顔の端に背景が見えないか（`side_fade`）。
- 眉とまつ毛が髪の上に出ないか、モーション中に首、口、目が崩れないか。

## Tripo Studio で作った頭

きゃらくるの Tripo Studio の手順で rig まで作った VRM は、頭に Tripo が描いた顔のテクスチャがあり、顔画像のアトラスはありません。次の順にします。

1. **飾りを分ける**: Tripo Studio の版は、頭の飾り(帽子、リボンなど)が `Head` と同じメッシュの別の材質に入っています。組み立ては `Head` を丸ごと外すので、先に分けます。
   `python studio/vroid/face_own/split_head.py <rig の VRM> <材料.vrm> Material_accessories`
2. **絵と正面を合わせる**(`align.mode: "direct"`): `front_view.py` で頭の正面を平行投影で撮り(1 画素 0.2 mm)、撮った画像と `neutral.png` の虹彩の中心を色で測ります。左右の虹彩の間隔の比が `dxdpx`、虹彩の中心どうしが重なるように `x0`、`y0` を決めます。目の開口は `mask.png`(緑の塗り)から読みます。
3. **肌の色を首に合わせる**: 肌は `skin.png` から作り、Tripo の頭のテクスチャは使いません(Tripo が描いた目と眉は残らない)。ビューアの正面の撮影で頬と首の色を測り、`skin_factor` と `skin_shade` に比を掛けます。
4. **首の範囲**: Tripo の頭は首の下まであり、体の首はあごより低い所で切れています。顔の面も首まで作らないと、下から見てあごと体の首の間が開きます。光線の中心を首の前の面より後ろに置き(`surface.center` の z を 0)、下の範囲を `surface.v` で -80° にします。-85° では真下へ向かう光線が首の開いた底を抜け、のどに穴が開きました。-62° ではあごで止まり、体の首の上端が見えました。

髪の材質の名前は版で違います(Tripo Studio 版は `Material_hair`)。内張りの色は `Hair` ノードの材質から取ります。

## 落とし穴

- **閉じた目に虹彩が刺さる**: 眼球の球は目の真ん中で面より前へ出ます。`add_lid_bump` で閉じたまぶたの面を持ち上げます。
- **歯が顎の下から透ける**: 下がった先の面は奥へ逃げます。`follow` が動かした先の面より奥へ押し込みます。
- **肌の斑**: 絵の外の明るい部分（背景、輪郭、耳）が `paint` の楕円に入ると、顎のあたりが明るくなります。頬の楕円は赤みの範囲に留めます。
- **頬とあごの凸凹**: 法線を正面の高さの表 Zf から出すと、輪郭の近くで面が横を向く所で崩れ、頬に明るい斑が出ました（持っている法線と面の差 p95 28.5 度）。法線は頭の面の表 r(u,v) から出します（`surface.normal_sigma`）。これで 1.7 度になりました。輪郭の折れは 3D の生成 の三角形の名残なので、頬から下を強くならします（`surface.jaw_sigma`、`surface.jaw_band`）。
- **組み立てに Blender を使わない**: 書き出し直すと材料の揺れものの細かい値が変わるためです。
