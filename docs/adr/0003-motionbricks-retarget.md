# 0003 MotionBricks の動きは、T ポーズからのワールドの回転の差で VRM の骨に移し替える

日付: 2026-10-30

## 決めたこと

- MotionBricks の SOMA の動きを、VRM 1.0 の humanoid の骨（正規化した骨）の回転と hips の位置にして VRMA に書く。
- 各骨について、SOMA の静止姿勢（T ポーズ）からのワールドの回転の差 `D = W(t) * W_rest^-1` を求め、VRM の骨のワールドの回転とする。ローカルの回転は `D_親^-1 * D_子`。
- VRMA の骨の節点は回転なしの T ポーズにし、位置は SOMA の静止姿勢の関節の位置にする。hips の移動は SOMA のメートルのまま書き、three-vrm-animation がキャラの hips の高さとの比で縮める。
- 書く骨は、きゃらくるの VRM にある骨だけにする: hips、spine、chest、neck、head、肩・上腕・前腕・手、脚の付け根・膝・足首・爪先。`upperChest` は書かず、SOMA の Spine2 の曲がりは chest に、Neck2 の曲がりは head に含める。指は書かない。
- 最初のコマで体が +Z を向き、hips の真下が原点に来るように、全体を Y 軸まわりに回して動かす。

## 理由

- SOMA の静止姿勢（`soma_base_skel_minimal_no_root.usd`）は、Y が上、前が +Z、左が +X の T ポーズで、VRM 1.0 の T ポーズと同じ向き（2026-10-30 に関節のワールドの位置と回転を出して確かめた）。座標の入れ替えも、A ポーズからの直しも要らない。
- ワールドの回転の差で移すと、SOMA の関節の軸の向き（ローカルの座標の取り方）に左右されない。VRM の正規化した骨は T ポーズでワールドの回転が単位なので、差をそのまま入れられる。
- きゃらくるの VRM（キャラ1〜4）には `upperChest` が無い。無い骨に回転を書くと、three-vrm はその回転を捨てるので、上の骨（首・肩）の向きがその分ずれる。
- hips の高さの比で縮めると、脚の長さと hips の高さの比が SOMA に近いキャラ（キャラ4 は 0.844、SOMA は 0.847）では、歩幅が脚の長さに合い、足の滑りが少ない。

## 考えた別の案

- 骨ごとのローカルの回転をそのまま写す。SOMA と VRM でローカルの軸の取り方が違うので、軸ごとの直しが要る。採らない。
- `upperChest` まで書く。VRoid の VRM では背中の曲がりが細かくなるが、きゃらくるの VRM では首と肩がずれる。採らない。
- 足の接地をキャラごとに IK で直す。VRMA はどのキャラにも当てる 1 つのファイルなので、キャラごとの直しは VRMA の外（ビューア）の仕事になる。今回は入れない（その後ビューアに入れた。`docs/foot-ik.md`）。
