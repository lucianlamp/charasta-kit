# 0002 版とモーションはコピーして固定し、コードとは別の保管場所に置く

日付: 2026-10-30

## 決めたこと

- 版（VRM）、モーション（VRMA）、セリフの音声は、取り込むときに保管場所へコピーし、以後は変えない。元の場所は記録だけする。
- 保管場所はコード（git）とは別のフォルダにする。設定ファイルの `libraryDir` で場所を指す。

## 理由

- 作業フォルダの VRM は上書きされ続ける（キャラ4の `chara4_body2.vrm` は 2026-10-30 の 1 日で 6 回上書きした）。また、片付けで消えることもある（同じ日に 6.8GB をごみ箱へ移した）。場所を指すだけでは、版の歴史が壊れる。
- 版は 1 つ 35〜55MB あり、git に入れると履歴が重くなる。コードを作り直したり clone し直したりしても、版は残したい。

## 考えた別の案

- 元の場所を指すだけ（容量が増えない）。版が上書きや片付けで変わるので採らない。
- コードと同じフォルダに置いて `.gitignore` する。コードを消すと巻き込まれるので採らない。
