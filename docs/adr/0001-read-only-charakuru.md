# 0001 きゃらくるは読むだけにする

日付: 2026-10-30

## 決めたこと

きゃらすたは、きゃらくるの正本（`.charakit`）とプロジェクトのフォルダを読むだけにし、書き込まない。表情付きの最終の VRM は、きゃらすたのバージョンとして持つ。表情スタジオの材料（骨とウェイト付きの Blender ファイル、顔の作業フォルダ）も、キットのフォルダからきゃらすた側の作業フォルダにコピーしてから使う。

## 理由

- きゃらくるは第三者が配布・更新するキットで、正本の形式や依頼の流れは予告なく変わりうる。書き込むと、その変化を追い続けることになる。
- キットの正本には、顔テクスチャ方式の表情を入れる場所がない（キットの表情制作はシェイプキー方式）。
- 2026-10-30 まで、顔の作業をキットのプロジェクトのフォルダで直接していた。中間ファイルが混ざり、骨を作り直すと顔の材料も上書きされた。

## 考えた別の案

- 最終の VRM をキットの正本へ登録し、キットの画面から書き出す。キットの登録の仕組みに合わせて作り、本家の更新を追う必要があるので採らない。
