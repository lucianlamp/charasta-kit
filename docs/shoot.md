# 撮る（完成モデルの動画）

完成モデルにモーション・セリフ・音声を当てた動画を作る。画面は完成モデルの「撮る」、ジョブは `shoot`。撮った動画は保管場所の `characters/<キャラ>/shoots/<ジョブ ID>/` に置き、動画ギャラリー（`docs/screens.md`）に出る。MV とショートも撮った動画として同じ場所に置く（`docs/shorts.md`）。

## 画面

動画は `shoot` ジョブ（下の「shoot ジョブ」）。

- 選べるもの: セリフ（なしが既定）、モーション（なしも選べる。既定は、前回このブラウザで選んだもの、無ければ名前が「全身を見せる」「挨拶」のもの、それも無ければ一覧の先頭）、表情（モーションに合わせる、ふだん、感情 5 つ）、写す範囲（全身・上半身・顔）、縦横（9:16、16:9、1:1）、画質（1080p 30fps、1080p 60fps、720p 30fps）、繰り返す回数（モーションがあるとき）か長さの秒（モーションもセリフも音声も無いとき）、音声ファイル（mp3、wav、m4a。64 MB まで）とその利用条件のメモ、「公開してよい」の選択（既定は選ばない）、音声の開始位置（秒）、背景（ビューアの色、白、黒、緑）。
- プレビュー: 枠は選んだ縦横に合い、中は `tools/shoot.mjs` と同じカメラ、表情、背景でモーションを流し続ける。カメラの計算はビューアの `aimShot` 1 か所。
- 音声が動画より長いとき: 動画の長さで切り、最後の 0.5 秒で音を小さくする。動画の長さは音声に合わせて伸ばさない（曲に合わせたいときは繰り返す回数を変える）。音声が短いときは残りを無音にする。モーションなしのときだけ、動画の長さがセリフと音声の長い方になる。画面の音声の欄に、どうなるかを出す。
- 音声の開始位置: 音声のこの秒から使う（既定 0）。動画の長さを音声に合わせるときは、開始位置より後ろの長さで決める。開始位置が音声の長さ以上のときは積めない。
- セリフと音声を重ねるときは、曲の音量を半分にする。セリフは 0 秒から始まる。
- 利用条件: 「この動画の利用条件」の枠に、選んだモーションと音声の条件を出す。判定は `lib/terms.mjs`。

| 記録 | 動画の扱い | 札 |
| --- | --- | --- |
| `license.evaluationOnly` が true、または `summary` に「個人利用」「私的利用」「公開不可」「公開禁止」「公開できない」「非公開」のどれか | 公開できない | 公開できない |
| `summary` に「二次利用禁止」「商用利用不可」 | 公開する前に確認する | 公開前に確認する |
| モーションの `summary` が空か無い | 公開する前に確認する | 公開前に確認する |
| 音声で、上の「公開できない」の書き方が無く、「公開してよい」を選んでいない（メモが空でも自由文でも） | 公開する前に確認する | 公開前に確認する |
| 音声で、「公開してよい」を選んだ | 公開を止める記録が無い | なし |
| モーションで、それ以外 | 公開を止める記録が無い。`summary` をそのまま出す | なし |

音声のメモは自由文なので、自由文だけでは「公開を止める記録が無い」にしない。「公開してよい」は画面の選択（既定は選ばない）で、メモに「公開できない」の書き方があればそちらが優先する。止めはしない（撮れる）。札は `shoot.json` の `terms` に残し、作ったものの一覧にも出す。札の文は、一覧を返すとき `terms.level` から今の文（`lib/terms.mjs` の `currentTerms`）に直して出す。文を直す前に撮った動画も新しい文になる。`level` が無い古い記録だけ、保存された文のまま。保管場所のファイルは書き換えない。`redistribution: false` は取り出せる状態での二次配布の話なので、動画の扱いには使わない（`docs/motions.md`）。

作ったものは、行を押して開く再生のモーダルで、再生とダウンロードと、撮った動画の「削除」（`docs/screens.md`）。

全身の撮影は、カメラの距離を時刻ごとに変える。前後 0.8 秒に全身が入る距離の最大を取ってからならすので、足を蹴り出す前に引き、それ以外は寄る（`zoomTrack`）。距離が固定だと、9:16 の枠は一番広がる瞬間の幅で決まり、ほとんどのコマで小さく映った。

## shoot ジョブ

完成モデルにモーション・セリフ・音声を当てた動画を作る。コードは `lib/shoot.mjs`（ジョブ）と `tools/shoot.mjs`（撮影）、カメラの計算は `public/shoot-plan.mjs` とビューアの `aimShot`。

入力: `charId`、`verId`、`motionId`（省くとモーションなし。腕を下ろした休めの姿勢）、`loops`（1〜10）、`seconds`（モーションが無いとき、180 秒まで）、`expression`（`motion`、`neutral`、感情）、`framing`（`full`、`upper`、`face`）、`aspect`（`9:16`、`16:9`、`1:1`）、`quality`（`1080p30`、`1080p60`、`720p30`）、`lineId`、`audioId`（`POST /api/audio` の返す ID）、`audioSummary`（200 文字まで）、`background`（`viewer` か `#rrggbb`）。

1. **長さを決める**: `shootSeconds`（`public/shoot-plan.mjs`、上の「画面」）。上限は 180 秒。ここで `timeoutMs` をジョブに書く（`shootTimeoutMs`: 120 秒 + 1 コマ 0.3 秒）。撮影とまとめるの合計がこれを超えると、外部コマンドを止めて `failed`。
2. **1 コマずつ撮る**: `tools/shoot.mjs` が GPU のブラウザ（`tools/gpu_browser.mjs`）で `/viewer?embed=1&follow=0` を開く。
   - ビューアの毎フレームの描画を止め、時刻を手で進める。再生の速さに左右されない。
   - 揺れ骨は 1 歩の dt で振る舞いが変わる（three-vrm の drag は 1 歩ごとに掛かる）ので、ビューアは画面の fps によらず揺れ骨だけ 1/60 秒の刻みで進める（`public/viewer.mjs` の `step`）。撮影も 1/60 秒で進める。30 fps は 2 歩で 1 コマ、60 fps は 1 歩で 1 コマ。
   - 最初の姿勢のまま、足の IK をかけて 3 秒分（180 歩）進めて揺れ骨を落ち着かせてから、最初のコマを撮る。
   - `Math.random` の種を固定する（まばたきの間隔）。同じ条件なら同じコマになる。
   - コマは品質 95 の JPEG。
3. **動画にまとめる**: H.264（High、yuv420p、CRF 18、BT.709 のリミテッドレンジ）、faststart。音声があれば AAC 192 kbps 48 kHz で、動画の長さちょうどにする。真ん中のコマを `poster.jpg` にする。
4. **記録する**: `characters/<キャラ>/shoots/<ジョブ ID>/` に `video.mp4`、`poster.jpg`、`shoot.json`（撮った条件、音声の名前と条件、`terms`）。ID ごとに別のフォルダで、前の動画は置き換えない。

カメラ（`aimShot`）: モーションを 1/15 秒ごとに測り（頭、胴、手足の骨。頭は休めの姿勢の大きさ、手足は体の高さの 4%、手は 7% の余白を取る）、視野は 30 度のまま距離を決める。

- 全身: 測った点が全部枠に入る距離と高さ。カメラは高さを変えず、左右の幅の真ん中と hips の前後を、前後 0.3 秒でならして追う。hips を追うと、足を大きく出したときに枠の幅が足りなくなるので、幅の真ん中を追う。ビューアの `follow` は使わない。
- 上半身と顔: 胴の長さと頭の大きさから枠の高さを決める（頭の大きいキャラも同じ構図になる）。頭を前後 0.3 秒でならして追う。手が枠の外へ出ることはある。
- 床のグリッドは 1 マス単位で寄せる。単色の背景ではグリッドを消す。

足の IK はオン。`paused` にしないのでビューアの再生と同じ。

音声ファイル: `POST /api/audio`（本文はファイル、ヘッダ `x-filename` は `encodeURIComponent` した名前）。保管場所の `audio/<id>/` に置き、`id` は中身のハッシュから作る。ジョブだけが読み、`/lib/` では配らない。

## API

| 道 | 中身 |
|---|---|
| `POST /api/audio` | 撮るときに重ねる音声ファイルを置く。返すのは `{id, name, ...}` |
| `GET /api/terms?motion=&audioName=&audioSummary=` | 動画の利用条件 `{level, tag, notes}`（`lib/terms.mjs`） |
