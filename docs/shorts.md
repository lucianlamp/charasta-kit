# ショート

カットを並べて作る縦動画（雑学、ドラマ、派手、ニュース、ダンス MV）。用語は `CONTEXT.md` の「ショート」から「動画の利用条件」まで。下書き（テーマから作る、Gemini、事実の確認、連載）は `docs/shorts-draft.md`、ダンス MV は `docs/shorts-dance-mv.md`、グラフィック MV は `docs/shorts-graphic-mv.md`、生き物を出すときの値は `docs/creature.md`。

## 画面

`public/short.mjs`。動画ギャラリーの「ショートを作る」から入る。ジョブは `short`（下の「short ジョブ」）。

- 型: 雑学、ドラマ、派手、ニュース、ダンス MV（`SHORT_STYLES`、表示名は `STYLE_LABEL`）。シリーズ帯は画面の上の小さな帯で、空なら出ない。下書き（テーマから作る）の型は `DRAFT_STYLES`（ダンス MV を除く 4 つ）。
- 編集画面: 人は確かめと微調整だけをし、操作はほぼエージェントがする前提で、画面は「確かめて、少し直して、直しを頼んで、確認済みにする」ためのもの。
  - 上の欄: 一覧へ戻る、題、保存の状態、型の札、動画の種類の札(立って話す、歩く 1 テイク、歩く 1 テイク · 枝の生き物あり)、長さ、「確認 n / N · 直し n」(直しは頼んで対応待ちの数。全体への頼みごとも数える)と確認の棒、「試しで書き出す」「本番で書き出す」。その下の行に、本番を止めている理由、書き出しを積んだ文、書き出しのジョブの進み具合が出る(無いときは行ごと出ない)。
  - 左の列: 出演者(色の点、名前、キャラ、声。「出演者を直す」の畳みに出演者の欄)、シーン(カットの使うシーン。歩くテイクは立ち止まる秒も)、生き物(歩くテイクだけ。下の「生き物を選ぶ」)、音(BGM、環境音、歩くテイクの足音。「音を直す」の畳みに環境音と BGM の欄)、全体への頼みごと、型とシリーズ帯、下書きの作り手と注意、事実の確認、連載、図を作る、書き出し(時間の目安と、畳んだ「書き出した動画」の一覧)。
  - 中央: そのショートの最新の書き出し(`/api/shoots` のうち `short.id` が一致する一番新しいもの)を再生する。カットを選ぶとそのカットの頭へ飛ぶ。再生中は今のカットを追って右の欄も移る(右の欄で打っている間は移らない)。前後のカット、再生と停止、今の時刻と全体の長さ、「書き出した絵に重ねて見る」を並べる。書き出しが無いときはビューアで選んだカットの動きと表情を確かめる(写す範囲はカメラの距離から決める)。
  - カットの時刻: 書き出しの時間表(`GET /api/shorts/<ID>/times/<preview|final>`。`work/<画質>/t.json` のカットの頭と終わり、声、効果音、BGM を止める区間)を、その書き出しの長さと 0.1 秒以内で合い、カットの数も今と同じときだけ使う。合わなければ声の長さの推定(`cutEstimate`)の累積で、時刻の前に「約」を付ける。
  - 右の欄: 選んだカットの番号、話す人、時刻、セリフ、声を聞く、テロップ(改行で 2 行)、カメラ、このカットで直してほしいことと「Claude に頼む」、「このカットを確認した」。畳み「演出と細かい設定」に、自動で決まる演出の説明、話す人、図、シーン、動き、表情(2 人以上は出演者ごとの行)、長さ、演じ方、音、生き物の動き(枝の生き物があるときだけ)、BGM を止める、転換、効果、テロップの型、話者の名札、図と図の説明。
  - 下のタイムライン: 秒の目盛り、カット(幅は長さに比例。書き出しから切り出したコマ、番号、カメラの 3 軸の名前、確認した印と直しを頼んだ印、選んだカットの枠)、セリフ(話す人の色)、テロップ、図(まだ作っていない図の説明は点線)、効果音(砂利の足音は目盛り)、BGM(止める区間は空く)、再生位置の線。見出しの行に、選んだカットの「前へ」「後へ」「このカットを消す」と「カットを足す」。コマは隠した video を seek して canvas へ描いて作る。書き出しが無いときはシーンの絵を出す。
  - スマホ(700px 以下): 上の欄(戻る、題、確認と直しの進み具合、試し、本番)、プレビュー(左右に前後のカット)、横に流れるカットの列(幅は長さに比例、下の帯は話す人の色)、カットの操作、右の欄の中身、左の列の中身の順に縦に積む。下のナビの上に大きな「このカットを確認した」を固定する。タイムラインの段は出さない。
- カメラ: 26 のカメラ（ダンス MV 専用の 5 つを含む。ほかの型のカットが選べるのは前からある 21）を「誰を撮る(話す人、決まった人、2 人、生き物、手紙) / 距離(大写し、寄り、胸から上、全身、引き) / 角度と動き」の 3 つの軸に置く(`public/short-camera.mjs`。対応表はデザイン案の COMBOS のまま)。軸の値を押すと、その値を持ち、ほかの 2 つの軸がなるべく今のままのカメラになる(同点なら表の先のもの)。動画の種類で使えるカメラが決まる: 立って話す 14、ダンス MV 8、歩く(`take` がある) 5、枝の生き物あり(`take.creature` がある) 7。使えない値は隠さずに薄くして押せなくし、理由を 1 行出す(ボタンの title にも出す)。手紙のカメラには「手紙を持つカットだけ」と添える。今のカメラがその種類で使えないときは選び直しを促す。構図の絵は人の形(1 人、2 人、生き物、手紙)と距離の枠。話す人のカメラは話す人を追う。手紙のカメラは持っている手紙を撮る。肩越しは手前に相手の肩と髪をぼかして入れる。
- 生き物を選ぶ: 歩く 1 テイク(`take` がある。ダンス MV は除く)の左の列の「生き物」。「なし」と、生き物のキャラ(`GET /api/overview` の `kind` が `creature` で、版があるもの)をサムネイルと名前の大きなボタン(`aria-pressed`)で並べる(`public/short-creature.mjs`)。
  - キャラを押すと `take.creature` を `{charId, perch, path}` の参照にする。`perch` と `path` は今の値があれば保ち、無ければ既定の 0 と、公園の並木道のシーンに合わせた既定の `path`。前の書き方から選び直したときは `flight` も保つ。同じキャラを押しても変えない(`verId` や上書きの値が残る)。「なし」は `take.creature` を消す。版は最新(`verId` を書かない)で、画面では選ばない。
  - 選んでいるときは「止まり木の番号」(0〜99 の整数。公園の並木道は 0〜2)を直せる。`path` の欄は無く、今の値のまま保存する。版の名前を 1 行で出す。
  - 前の書き方(`blend` を持つ)のショートは、押された状態の「前の書き方」の行に blend のファイル名を出し、開いて保存しただけでは変えない。キャラを選び直したときだけ参照に置き換える。参照しているキャラが一覧に無いときも、押された状態の行で出す(サーバーが保存を断るので選び直す)。
  - 選ぶと動画の種類の札、使えるカメラ(生き物の 2 つ)、右の欄の「生き物の動き」がその場で変わる。カットの `creature` は「なし」にしても消さない(生き物が無いときは撮るときに使わない)。
  - 生き物の動き: 首をかしげる(tilt)、下を見る(down)、じっと見る(stare)、鳴いて飛び立つ(takeoff)。選んだ生き物の最新の版の動き(前の書き方は `take.creature` そのもの)に無いものは「(この生き物に無い)」を付けて選べなくする(`takeoff` は `clips.caw` と `fly` が要る。サーバーの `checkCues` と同じ決まり)。今の値が無い動きのときは選んだままにして、足りないものを注意に出す(撮る前にサーバーも断る)。
- 確認と直しの頼みごと: カットに `ok`(確認した)、`ask`(直してほしいこと、200 字まで)、`askedAt`(「Claude に頼む」を押した ISO の時刻)を、ショートに `ask` と `askedAt`(全体への頼みごと)を保存する。「Claude に頼む」は `ask` を保存して `askedAt` を入れるだけで、処理は別。Claude は `scripts/short-asks.mjs list` で対応待ちを読んで直し、`done` で片付ける(charasta スキルの「ショートの頼みごとを進める」)。片付けると `reply`(何をしたか、200 字まで)と `repliedAt` が残り、頼みごとの下に「Claude の対応」として出る。頼みごとと時刻は消え、カットの `ok` も外れる。頼みごとを空にすると時刻も消える(サーバーも空の頼みごとの時刻は残さない)。どれも絵の ID と台本のキーに入らないので、描き直しも主張の確認のやり直しも起きない。
- 出演者: 左の列の「出演者を直す」で 1〜3 人を並べる。名前、キャラ、版、声の提供元（VOICEVOX、ElevenLabs）、声を選ぶ。VOICEVOX は話す速さも選ぶ。2 人以上は名前が要り、名前を変えるとカットの話す人も変わる。ElevenLabs の声はキーがあるときだけ出て、日本語の professional の声だけが並ぶ。
- 2 人以上のカット: 話す人を選ぶ。出演者ごとに動きと表情と、そのカットに出るかどうかを選ぶ。話す人が「語り」のカットは口が動かない。
- 2 人以上のカットの出演者の行: 小道具（手紙の最後の行を折る、開く）と、動きの最後の姿勢から始める、を選べる。演出の「BGM を止める」はそのカットの間 BGM を消す。
- 演じ方: 話す人が ElevenLabs の声のカットに出る。音: カットの頭近くで鳴らす足音、紙の音、チャイムなど。環境音: 全体に薄く敷く音。
- カット: シーン、動き、表情、カメラ、セリフ、テロップ。テロップは改行を入れられ、改行があると欄が 2 行になる(最初のカットのフックの帯は前置きと題の 2 行で出る)。カットの長さは声で決まる。長さを指定すると、声より長いときに効く。セリフが空のカットは指定の長さで、指定が無ければ 2.5 秒。
- セリフの `[語]` は強調の印。声と字幕には括弧を除いた文を使い、声の作り直しもコマの描き直しも起きない。`[語|surprised]` はその語の時刻に表情も変え、そのカットは描き直す。
- 演出: 右の欄の「演出と細かい設定」で、転換、効果、テロップの型、話者の名札、図を選べる。「自動」のままなら文から決まり、何に決まるかを 1 行で出す。
- 編集は 0.8 秒で自動で保存する。書き出しを押すときも先に保存する。
- 書き出した絵に重ねて見る: 書き出し済みのカットの絵に、今の文字と演出を重ねて再生する（HyperFrames のプレーヤー）。文字の直しは書き出さずに見られる。セリフやカットの数を変えたときは書き出しが要る。転換と効果音は次の書き出しで変わる。
- 声を聞く: 話す人の提供元の声でそのセリフだけ作って鳴らす。ElevenLabs の声は保管するので、同じ文、声、演じ方なら生成し直さない。
- 試しと本番はカットの絵の画質が違う。動画はどちらも 1080x1920。直したカットだけ描き直すので、2 回目からは短い。
- BGM: 音声ファイルが無いときは、チェックを入れると型の既定の BGM を使う。雑学の見本は入っている。
- 雑学の見本: 1 つのシーンでカメラと図で変化を付け、最後は問いで切って最初の話題へ戻る（ループしやすい）。
- ドラマの見本: 「夕暮れの手紙」。2 人の出演者で 10 カット、約 24 秒。凛が手紙を持ち、手紙の寄りと最後の行を見せる。avatar-sample-b と beta-sample-2 があれば使い、無ければ版のある最初の 2 人を使う。キーが無ければ声は VOICEVOX になる。
- カードの「本番で書き出す」は、その時点のカット表で書き出す。
- 図を作る: 左の列の「図」のボタン。図の説明があって図の無いカット全部の図を Codex で作る（1 枚に数分）。進み具合はボタンの下に出る。できた図は「演出と細かい設定」の中に小さく出て、押すと原寸で見られる。「作り直す」でそのカットだけ作り直す。人が入れた図は上書きしないので、作り直すのボタンも出ない。失敗したカットは結果の文に出て、もう一度押すと残りだけ作る。

## short ジョブ（ショート動画）

カット表から、声、口の動き、文字と演出の付いた縦動画を作る。コードは `lib/short.mjs`（ジョブ）、`lib/short-voice.mjs`、`lib/voicevox.mjs`、`lib/elevenlabs.mjs`（声）、stage-studio の `tools/make_short.py`（絵の描画）、`lib/short-compose.mjs` と HyperFrames（文字と演出）。カット表は `shorts/<id>/short.json`。

下書きから作ったショートは `claims`、`serial`、`draft` も持つ（`docs/shorts-draft.md`）。`short.json` の `cast` は出演者の配列（1〜3 人）で、`{name, charId, verId, provider, ...}`。`provider` が `voicevox` なら `speaker`、`speakerName`、`speed`、`elevenlabs` なら `voiceId`、`voiceName`。`cast` の無い古いファイルは `castOf` が 1 人の出演者として読む。先頭の出演者の `charId`、`verId` は、記録と編集画面のためトップにも持つ。カットの追加の欄: `who`（話す人の名前）、`actors`（出演者の順の `{motionId, expression, absent, turn}`。無ければカットの動きと表情を全員に使う）、`sound`、`soundAt`、`tone`。ショートの `ambience` は環境音。

入力: `shortId`、`quality`（`preview`、`final`）。ジョブはカット表の写しを持ち、積んだあとの編集の影響を受けない。要確認の主張が残るショートの `final` は積めない。

セリフの `[語]` は強調の印で、括弧を除いた文を声と字幕に使う（`public/short-direct.mjs` の `parseMarks`）。声のキャッシュとカットの ID も括弧を除いた文から作るので、印を足しても声とコマは作り直さない。`[語|surprised]` はその語の時刻に表情も変える。表情は絵に入るので、これを変えるとカットを描き直す。指定できるのは neutral、happy、angry、sad、relaxed、surprised。

1. **声を作る**: 話す人の声の提供元で作る（下の「声の提供元」）。VOICEVOX は VOICEVOX Engine（`config.voicevoxDir`）で wav と音の時刻を作り、`shorts/<id>/voice/` に置く。テンポのために `pauseLengthScale` 0.5、前後の無音 0.05 秒、`intonationScale` 1.3 にする（`VOICE_TUNING`）。話す速さの既定は 1.25。文、話者、速さ、`VOICE_TUNING` が同じなら作り直さない。エンジンが動いていなければ起動し、サーバーの停止で止める。自分が起動していないエンジンは止めない。
2. **長さと口を決める**: カットの長さは 声の長さ + 0.1 秒（「？」で終わる文は 0.45 秒。問いのあとの間）と指定の長い方で、コマの境に揃える。ドラマの型は声の後ろに 0.08 秒だけ足す。ElevenLabs の音は文末の無音を数えず、最後の文字の終わりから測る(`speechEnd`)。音の頭に約 0.2 秒の無音があるので、セリフの間は 0.2〜0.3 秒になる。最後のカットは 0.35 秒で、その間は暗転する。7 秒を超えるとログに出す。モーションも繰り返さず最後の姿勢で止める（`bake_motion.mjs --once`）。口が動くのは話す人だけで、心の声と語りは動かない。口はコマごとの形をビューアの `mouthOverride` で渡し、焼き込みに入れる。語の時刻の表情は同じ配列の `emotion` で渡し、語の時刻から 1.6 秒出す（ビューアが読むので stage-studio は変えない）。あわせて timeline を `t.json` へ保存する（下の「timeline」）。
3. **コマを描く**: `make_short.py` がカットごとに、出る人それぞれを焼き込み（動き、表情、口）、Blender の 1 つのシーンに並べて描く。カットの ID は絵が変わる条件（出る人ごとの版とモーションの中身、表情、口、シーンのコード、描画の道具、カメラ、長さ、画質）のハッシュなので、変わらないカットは描き直さない。立ち位置とカメラは下の「2 人の描画とカメラ」。
4. **文字と演出を重ねる**: 下の「合成」。
5. **記録する**: 撮った動画として保存する（`kind: 'short'`）。札はモーションと音声のうち一番重い扱い。VOICEVOX の声を使うと、投稿の説明に書くクレジットをカードに出す。話者ごとの規約は人が確かめる。

作業は `shorts/<id>/work/<quality>/` に残し、今のカット表に無いカットだけ消す。

## 歩く 1 テイク（take）

カット表に `take` があると、全カットを 1 つの時間の流れで撮る（歩きながら話す動画）。`take`: `motions`（出演者の順の歩く動き）、`mark`（歩き始めの地面の位置）、`spread`（中心から左右への距離）、`look`（話す人が相手へ首を回す度）、`creature`（枝の生き物。stage-studio の `lib/creature.py` の spec から `events` を除いたものをそのまま書く（前からの書き方。`blend` に Blender のファイルのパスと全部の値）か、ライブラリの生き物のキャラを参照する `{ "charId": "crow", "verId"?, "perch", "path", "yaw"?, "flight"?, "scale"?, "drop"? }`（`perch` と `path` が要る。`charId` は `style` が `creature` のキャラで、`verId` を省くと最新の版。保存の前に、キャラと版が生き物かを確かめる）。参照は撮るときに `{ blend: <版の model.blend の絶対パス>, ...creature.json の値, ...ここに書いた値 }` へ解き（ここに書いた値が優先）、stage-studio へ渡す。コマの ID には版の blend の sha256 を混ぜるので、blend を取り込み直すと撮り直しになる。カットの `creature` が使う動き（`tilt`、`down`、`stare` は同じ名前の `clips`、`takeoff` は `clips.caw` と `fly`）が creature.json に無ければ、撮る前に断る。生き物のキャラは、このショートの出演者（`cast`、`charId`）には選べない。ショートはそのキャラの `appearances` に出る。編集画面の左の列の「生き物」で選ぶと参照の書き方で入る（上の「画面」））、`springs`（出演者の順の揺れ骨の値。`{"skirt": [硬さ, 抵抗]}` は骨の名前に skirt を含む揺れ骨の stiffness と dragForce を置き換える。要らない人は `null`）、`stop`（動画の 0 秒からの秒。全員が歩きを止める。焼き込みの 0 秒と動画の 0 秒は同じ。前後 0.6 秒の中で両足が地面に着いたコマを選び、手前の約 0.3 秒でモーションの進みを 1 から 0 へ落としてそのコマで止まる。止まったあとも揺れ骨、まばたき、表情、口、首の向きは進む。動画より後の秒は保存できない。stage-studio の `tools/bake_motion.mjs --stop`）、`footsteps`（`true` のとき、焼き込みが書き出す `steps`（左右の足首の高さから測った、かかとが地面に着いた時刻）ごとに砂利の足音 `gravel` を鳴らす。撮ったあとに音を混ぜるときに足すので、コマの ID には入らず、足音だけの直しは音の作り直しで済む。動画は焼き込みより 1 コマ早い（Blender は 1 番のコマから描き、焼き込みの 0 番目ではなく 1 番目の姿勢を最初に描く）ので、鳴らす時刻は `steps` から 1 コマ引く。強さは歩の番号から決め（乱数は使わない）、ピークは約 -15 dBFS（1 歩の瞬間のラウドネスで語りの約 17 LU 下）で語りの下に敷く。`stop` もあるときは、焼き込みの `stop.t`（止めたコマの秒）で砂利を擦る音 `scuff` を 1 人 1 回(足音と同じく 1 コマ引く)、足音より 6 dB 強い約 -9 dBFS で鳴らす）。カメラは `front_walk`、`side_walk`、`back_walk`、`diag_walk`（斜め前の 2 人）、`walk_close`（話す人の胸から上を前から）、`crow_close`（カットの `angle`（-180〜180 度）で枝の生き物のまわりを上から見て左回りに回る）、`crow_takeoff`（立ち止まった 2 人の前の低い三脚から、2 人と頭の上の空を見上げる。飛び立った生き物が上を横切る終わりのカット）。カットの `creature`（`tilt`、`down`、`stare`、`takeoff`）はカットの始めに生き物がすること。カットの `actors[].gaze` は 1 テイクの首の向き: `up` は前を向いたまま見上げ、`each` は話す人に関係なく相手の方を向く（どちらも `take.look` より優先。焼き込みの `lift` と `look`）。会話の経路の口は開きの最大を 1 にする（1 文ずつの経路は 0.8）。

### 声の提供元

出演者ごとに `voicevox` か `elevenlabs` を選ぶ。ElevenLabs は `lib/elevenlabs.mjs`。

- キーは環境の `ELEVENLABS_API_KEY` だけから読み、リクエストのヘッダーにしか載せない。ログ、画面、ファイル、エラーの文に出さない。無いと画面の提供元に出ない。
- 音は `/v1/text-to-speech/{voice_id}/with-timestamps`（`mp3_44100_128`）。字幕の時刻は返ってきた文字の時刻をそのまま使う（`alignedChars`）。演じ方のタグと心の声の括弧は文字の突き合わせで飛ばす。
- モデルは `eleven_v3`、`stability` 0.5、`similarity_boost` 0.75。`eleven_v3`、`eleven_v4`、`eleven_multilingual_v2` の 3 つとも timestamps を返す。`eleven_v3` は音声タグで演じ分けられるので選んだ（比べた記録は `docs/notes/shorts.md`）。v3 の文字の時刻はかなにも漢字にも付く。
- 使える声は `usableVoice`: `category` が professional で `labels.language` が ja のものだけ。名前に lucian を含む声と cloned の声は一覧にも出さず、生成の前にも確かめて断る。
- 出演者が 2 人以上で全員 ElevenLabs のショートは、全カットのセリフを `/v1/text-to-dialogue/with-timestamps`（`eleven_v4`、`language_code: ja`、`seed` あり）へ 1 回で送る。行の切り位置は元の音の波形で決める(`voice_segments` の境目は声の始まりより 0.3 秒ほど遅いことがある)。探す範囲は、その行の `alignment` の最後の発音される文字(句読点、括弧、空白を除く)の開始時刻から 0.3 秒引いた位置(`alignment` も声より遅れることがある)から、境目の 0.1 秒後まで。範囲内で 30 ms 以上続く無音のうち境目に一番近いものの末尾を次の行の始め、始まりから 30 ms 後を前の行の終わりにする(終わりの 30 ms が無音になる)。下限は、最後の文字の開始時刻の直前の声の連なり(30 ms 以上の無音で区切る)の始まりより前にならない(語の中の短い息継ぎは境目にならない)。範囲に無音が無いときは、境目の 0.6 秒後までの最初の無音を使う(境目が声の終わりより早いことがある)。下限より前の無音は使わないので、最後の語の前の溜めは行の境目にならない。無音が無ければ範囲内で一番小さい 10 ms を境にする。前の行の終わりは次の行の始まりを超えない。切る前に各行の始まりの前 30 ms が無音であることを確かめ、違えばジョブを止める。さらに、各行の終わりの 30 ms が無音か、最後の語が行の区間に残っているか、次の行の頭に前の行の最後の語が入っていないかを `alignment` の時刻から確かめ、外れたら作業の記録に警告を出す(止めない)。文字の時刻は行の区間へ写し、`atempo` で 1.1 倍速にして、文字の時刻も同じ倍率で縮める。カットの間は声のあと 0.1 秒。ElevenLabs と VOICEVOX が混ざる出演者のときと 1 人のショートだけ、1 文ずつの経路(v3)のまま。演じ方(`tone`)のあるカットは、その行の先頭に v4 のタグ(`[whispers] ` のように `lib/elevenlabs.mjs` の `DIALOGUE_TAGS` で対応づけた英語 1 語)を付けて送り、tone の無い行にはタグを付けない(タグは文字数として課金され、付けすぎると息や笑いが強く入りすぎる)。alignment にはタグの文字も入るので、`dialogueLine` が行頭のタグの文字を除いてから文字の時刻を写す。声の無いカットは inputs に入れず、行の番号は声のあるカットの並びで数える。キャッシュは `voice-cache/<ハッシュ>.mp3` と `.json`（台本全体(タグ込みの文)、声、モデル、seed がハッシュの中身）、切り出しは `<ハッシュ>-<切り方のハッシュ>-<行>.wav`。v3 のキャッシュとは別のキーで、壊さない。
- 声は保管場所の `voice-cache/<ハッシュ>.mp3` と `.json`（文字の時刻、読み、消費）に置く。ハッシュは文、声 ID、モデル、設定、演じ方。ショートをまたいで同じ文を生成しない。VOICEVOX の声はこれまで通りショートの `voice/`。
- 口の動き: ElevenLabs の文字の時刻は読みが分からないので、VOICEVOX の `audio_query` で読みと母音を取り、句読点の区間ごとに ElevenLabs の時刻へ伸縮する（`elevenPhrases`）。区間の数が合わないときは文全体で伸縮する。VOICEVOX が動いていなければ wav の音量で口を動かし（`levelLips`）、読みは次に取れたときに保管する。
- `CHARASTA_FAKE_ELEVENLABS=1` で API を呼ばず、文の長さの無音と文字の時刻を返す。テストはこの経路だけを使う。

### 2 人の描画とカメラ

stage-studio の `lib/shots.py` と `tools/render.py`。カットの人は `cast.json`（`{glb, yaw, slot, count}`）で渡し、`slot` は立ち位置の番号。

- 立ち位置（`stand`）: 2 人はシーンの mark の左右へ 0.6 m、互いへ 60 度回す（45 度では肩越しで相手の方を向いて見えなかった）。シーンの `facing` に合わせて回る。`actors[].turn` はカットごとにこの向きへ足す度で、動きが体を回す分を打ち消す。3 人は左右へ 0.9 m と中央の奥。1 人は今まで通り mark。
- カメラはカットの `who` の人を追う。`close_who`（寄り）、`bust_who`（胸から上）、`over_shoulder`（肩越し。相手の頭の後ろ 0.7 m、手前へ 0.42 m、f 1.8 で相手をぼかす）、`two_shot`（2 人の引き）、`pull_back`（寄りから部屋が見えるまで引く）。どれも想定線の手前側に置くので、左の人は常に画面の左に出る。
- 顔は画面の上 3 分の 1 に置く（`third_z`）。下の 3 分の 1 が字幕の場所になる。
- カメラは `clear_bodies` で人の頭の軸から 0.4 m 以内に入らない。`tools/test_shots.py` が幾何を確かめる（bpy は要らない）。
- これらのカメラはカメラに付けた柔らかい光を 0.2 倍、キャラの自己発光を 0.45 倍にし、シーンのブルームを弱める。さらに顔のテクスチャの明るさ(`skin_level`)から倍率を出し(`skin_gain`)、明るいキャラは基本色も下げて、2 人の顔の明るさをそろえる。

- 小道具: 出演者の `actors[].prop` は右手に手紙を持つ。`letter` は最後の行のある左の 4 分の 1 を裏へ折り、`letter_open` は開く。stage-studio の `tools/make_letter.py` が行書体の本文を書いたテクスチャを作る。紙は位置だけ手に従い、立てたまま相手と手前の間を向ける。`prop_close` は手紙の寄りで、頭に素早く寄る。`prop_line` は最後の行を上からなぞる。`actors[].hold` は動きの最後の姿勢から始める。指は `bake_motion.mjs --grip` で曲げる。
- 顔: カットの表情に感情のほか `worried`、`afraid`、`shocked`、`tense`、`cold` を選べる（`SHORT_FACES`）。`bake_motion.mjs` が Fcl_ の形を重ね、口は開かない。

### timeline と自動演出

`work/<quality>/t.json` は HyperFrames の合成へ渡す 1 本の JSON で、`lib/short-timeline.mjs` の `buildTimeline` が作る。時刻はすべて動画の頭からの秒。

- 全体: `style`、`series`（シリーズ帯）、`caption`（字幕の型）、`letterbox`、`width`、`height`、`fps`、`seconds`、`cuts`、`sfx`（`[{name, t, gain}]`）。
- カット: `id`、`start`、`end`、`count`、`frames`（作業フォルダからのコマのパス）、`stage`、`camera`、`expression`、`text`（括弧なし）、`telop`、`who`、`whoColor`、`direction`、`marks`（`[{text, t}]`）、`punches`（ズームパンチの時刻）、`voice`（アクセント句とモーラの時刻）、`captions`（字幕の句）。
- 字幕の句: 読点と句点の間、または 2 行に収まらなくなる所で切り替える。1 行 10 字、1 画面 18 字まで、改行はアクセント句の境。語りの 0.25 秒前に出し、句の間を 0.15 秒あけ、最短 0.5 秒。`chars` は 1 文字ごとの `{c, from, to, em}`、`lines` は行ごとの字数。かなは声のモーラに合わせ、助詞の「は」「へ」「を」は読みで合わせ、漢字などは前後のかなの間を重みで割る。読んでいる文字の色はこの時刻で進む。

演出は `direct(cuts, style)`（`public/short-direct.mjs`）が文から決める。乱数は使わず、同じ入力には同じ答えを返す。

- 型（`style`）: `trivia`（雑学）、`drama`（上下の黒帯、控えめな字幕、ディゾルブ、飾りなし）、`pop`（派手）、`news`（帯）。ショートに持たせ、無ければ `trivia`。
- ドラマの型: 字幕は話す人の色のゴシックに黒縁と半透明の帯を付け、句読点で切らず 1 画面に続けて出す。文字の塊の中心は y 1440 に固定する。2 人の会話では名札を出さない。心の声は明朝で色を抜く。黒帯は上下 130 px。転換は既定で直につなぎ、シーンが変わると黒を挟む（`fade`、34 コマ）。ディゾルブは時間が経つカットに人が選ぶ。最初のカットのテロップは顔より上の見出し（`title`）。最後は言い終わりで即座に暗転し、最後のカットのテロップは暗転の 0.3 秒だけ出る。カットの `hush` は BGM と環境音を止める。カットの `soundGain` は音の倍率。
- カットの種類: 最初はフック、最後は「フォロー」を含む文ならフォローの誘導、含まなければ終わり（定型の誘導は足さない）、そのほかは「？」で疑問、「！」で強調。テロップの数字は `number` に入り、テロップの型が数字になる（カウントアップ）。最後のカットより前で一番あとの、6 字以内の強調語か短いテロップを全画面で見せる（オチ）。文全体が括弧で囲まれたカットは心の声で、書体を変える。
- テロップは見出しで、字幕の繰り返しにしない。最初のカットのテロップが空なら型の見出し（雑学は「衝撃の雑学」）を出す。フックの帯のテロップに改行を 1 つ入れると 2 行になり、1 行目は白の前置き、2 行目は題として字数から大きさを決める（9 字で約 96 px。1 行のままだと 12 字で 63 px）。カットの音 `caw` はカラスの 1 声（0.6 秒）。数字は字幕でも算用数字で書く（VOICEVOX は「3つ」をミッツと読む）。
- 驚きの語（なんと、まさか、えっ、驚、びっくり、しかも）は、反応の型（雑学、派手）で自動で surprised にする。
- 図: カットの `figure` は `shorts/<id>/figures/` のファイル名。最初の強調語の時刻に弾んで出て、2.2 秒で消える。手動の図は丸く抜くので背景のある絵でよい。`figureStyle: 'sticker'`（`short-figures` ジョブが作った図）は透過のまま、丸いカードより大きく出し、白い縁と影で背景から分ける。位置はカメラごとに `public/short-fx.js` の `L.sticker`（顔、字幕、テロップに重ねない）で、フックの帯が上を占めるカットは `L.hooked`。表に無いカメラは `talk_bust` の位置(左上、一辺 400)になる。歩く動画では `crow_close` だけを表に入れ、生き物の頭より上の明るい葉のぼけに一辺 700 で出す(フックの帯があるカットは帯の下に一辺 520)。書き出すと合成のフォルダへコピーする。
- 1 カットの主な効果は 2 つまで。カットの `transition`、`effect`、`telopType` が空なら自動、値があれば上書きする。

### 合成

作業は `work/<quality>/compose/`。上から順に作り、入力のハッシュが同じものは作り直さない。文字や演出だけの直しは Cycles も base も mix も動かない（30 秒の動画で約 1 分半）。

1. **base.mp4**: カットのコマをつなぎ、カットの境の前後のコマを転換で置き換えて 1080x1920 の動画にする。転換は `lib/short-transitions.mjs`（whip、zoom、flash、slide、glitch、dissolve）が前後のコマの画素から作る。鍵はカットの ID と転換と転換の種。転換の種はセリフだけから作るので、テロップの直しでは作り直さない。
2. **mix.wav**: 語り、BGM、環境音、効果音を混ぜる。語りの積分ラウドネスは話す人ごとに測って -15 LUFS にそろえ、BGM を -23 LUFS（ドラマは -26 LUFS）、環境音を -33 LUFS にそろえ、BGM は語りの間だけ約 4 dB 下げる（`sidechaincompress`）。効果音は素材のピークから -5 dB で、素材ごとの補正は `SFX` の `db`。全体はリミッターでピークを -3 dBFS 以下にする。BGM はカット表の音声ファイルか、`defaultBgm` が真なら型の既定の BGM（`assets/bgm/`。`tools/make_bgm.py` が合成）。
3. **index.html**: HyperFrames のプロジェクト。`<video>`（base）、`<audio>`（mix）、SVG 1 枚と、`public/short-fx.js` の埋め込み。`short-fx.js` は `hf-seek` の時刻の純粋な関数で SVG とカメラの `transform` を描く。GSAP は使わない（`gsap` がディスクに無く、ダウンロードしない方針のため）。
4. **書き出し**: `config.hyperframesCli` の CLI を node で直接呼び、`check` のあと `render --gpu` する。CLI と Chrome(`config.hyperframesBrowser`)が無ければ Cycles の前に失敗する。`check` は問題があると終了コード 1 で終わるので報告の中身で判断し、lint と runtime の誤りで止める。layout は重ねた縁取りの層を文字の重なりと数え、contrast は縁のある文字を見ないので、ログに残すだけにする。`render` の出力に `[Browser:PAGEERROR]` があればジョブを失敗にする。`CHARASTA_FAKE_CAPTURE` では HyperFrames を呼ばず、base と音だけをつなぐ。

HyperFrames の CLI の注意:

- テレメトリーは `HYPERFRAMES_NO_TELEMETRY=1` と `DO_NOT_TRACK=1` で切る（`hyperframesEnv`）。一時ファイルは `compose/tmp` に置き、ジョブの最後に消す。
- `snapshot` は `GEMINI_API_KEY` があるとコマを Gemini へ送る。環境から API キーを外して呼ぶ。
- `font-family` に名前だけ書くと、コンパイラーが足りない分を Google Fonts から取りに行く。`@font-face` を自分で書いたファミリー名（`ShortSans`、`ShortRound`、`ShortSerif`）だけを使う。
- エンジンのシェーダー転換（`window.__hf.transitions`）は `HF_PAGE_SIDE_COMPOSITING=false` で動くが、6 秒の動画に約 2 分かかり、転換の間は文字も消えるので使わない。ページ側の合成は `@hyperframes/shader-transitions` が要り、手元に無い。
- インラインの `<script>` と `src` の付いた `<script>` は順序が保たれない。データとコードは 1 つのインラインの `<script>` に入れる。
- GSAP の timeline が無いので、ルートに `data-no-timeline` を付ける。無いと 45 秒待つ。

文字と飾りの基準（`public/short-fx.js`）:

- 安全域: 上 180、下 380、左 60、右 150。投稿先の UI に隠れる位置に重要な文字を置かない。カメラごとの高さは `LAYOUT`。寄りのカメラは顔の上に空きが無いので、テロップを胸に置く。
- カメラ: 全カットを少し動かす。引きのカットは寄りの 3 倍ズームし、横にも流れる（後処理なのでコマは描き直さない）。
- 字幕 72px、強調語は 1.3 倍。塗りは白、読んだ文字の黄、強調のピンクの 3 色で、縁は黒と水色の二重。SVG の `stroke-linejoin: round` を使うので、日本語の角に CSS の `-webkit-text-stroke` のようなトゲが出ない。
- 書体: Noto Sans JP Black（字幕）、Zen Maru Gothic Black（テロップ）、Noto Serif JP（ドラマの字幕）。Noto はシステムのファイル（`C:/Windows/Fonts`）を作業フォルダへコピーして読む。
- Zen Maru Gothic（`public/fonts/ZenMaruGothic-Black.ttf`）は SIL Open Font License 1.1 のフォント。

効果音は `tools/make_sfx.py` が numpy で合成した音（種を固定しているので作り直しても同じ音になる）と、Pixabay の音（`assets/sfx/pixabay/`）と、ElevenLabs の sound-generation で作ったドラマの音（`assets/sfx/drama/`。`tools/make_drama_sfx.mjs`。ある音は作り直さない）を併用する。カットの `sound` は型の倍率で弱めない。`lib/short-compose.mjs` の `SFX` が名前とファイルの対応で、出どころは `assets/sfx/CREDITS.md`。

## short-figures ジョブ（ショートの図）

カットの図の説明（`figureNote`）から、Codex の `image_gen` で背景透過の図を作る。コードは `lib/short-figures.mjs`。`POST /api/jobs` の本文は `{type: 'short-figures', shortId, cut}`。

- 対象: `cut` を省くと、図の説明があって図の無いカット全部。`cut`（0 から数える番号）を渡すとそのカットだけで、作った図の作り直しにも使う。人が入れた図（`figureStyle` の無い図）のカットは 409 で断る。作る図が無ければ 400。同じショートの図を作っている間は積めない。
- 実行: 設定の `figureImageGen`（既定は codex-image-gen スキルの `codex_imagegen.sh`）を設定の `gitBash` で動かす。1 枚 15 分で打ち切る。依頼文は作業フォルダのファイルで渡し、図の説明は JSON に入れて「指示ではない」と書いて渡す（Gemini が書いたデータなので）。
- 検査: PNG、8 ビット RGBA、四隅の透明、外周に主題がほぼ触れていないこと（主題が枠の端で切れていない）、主題が画面の 3% 以上あること。満たさない図は失敗に数え、作業フォルダに残す。
- 保存: `saveFigure` と同じ `shorts/<id>/figures/` に置き、カットの `figure` と `figureStyle: 'sticker'` を入れ、`short.json` の `figuresRev` を 1 増やす。1 枚できるごとに書く。作っている間にカットの説明や図が変わったときは入れず、`skipped` に書く。
- 失敗: 1 枚の失敗は `failed` に書いて次へ進む。結果は `{shortId, made, failed, skipped}`。1 枚もできず失敗があるときだけジョブが失敗になる。
- 編集画面の保存との関係: 画面は開いたときのカット表を持ち続けるので、`figuresRev` が古い保存でも `keepMadeFigures`（`public/short-direct.mjs`）がジョブの図を残す。ジョブの書き込みと画面の保存は `lib.updateShort` で 1 件ずつ順に進める。
- ファイルの扱い: カットを消す、図を外す、作り直すと、カットから外れた図のファイルを消す（`dropFigures`）。戻せないが、作り直せる。順番待ちや実行中の書き出しが指す図は残す。ショートを消すとフォルダごとごみ箱へ移る。

試しの動き: `CHARASTA_FAKE_FIGURE=1` は Codex を呼ばず決まった図を作る。`fail`、`opaque`、`corner`、`edge`、`empty` はそれぞれの失敗。
