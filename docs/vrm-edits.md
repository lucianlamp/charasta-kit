# VRM の体を直す

キャラの体の比率は、VRM の glTF を直接書き換えて直す。Blender で読み込んで書き出すと、揺れ骨とコライダーの設定が崩れることがあるため（コライダーの警告が出る）。直した VRM は新しいバージョンとして取り込む。バージョンは上書きしない。

```bash
node scripts/import-version.mjs --char <キャラ> --id <新しいバージョン> --label "<何を直したか>" --src out.vrm --latest
python tools/make_lite.py <バージョン>/model.vrm <バージョン>/model-lite.vrm
node tools/thumb.mjs --char <キャラ> --ver <新しいバージョン>
```

体を変えたバージョンでは、バージョンに合わせて焼いたモーション（手のめり込みの直し、足を床に付ける焼き込み）を測り直す。

## 体型（`tools/vrm/body_shape.py`）

画面の「体型と揺れもの」のジョブ `adjust`（`docs/adjust.md`）が使う。手で使うこともできる。

```bash
python tools/vrm/body_shape.py in.vrm --probe                                   # 骨の高さと、それから決めた区間(JSON)
python tools/vrm/body_shape.py in.vrm out.vrm --head 0.94 --neck 0.0075 --shoulder -0.024 --arm 0.8 --waist 0.95 --leg 0.9
```

- 値は省くと変えない。`--neck` と `--shoulder` は m（`--shoulder` は片側、正は広く）、ほかは倍率。範囲の外は終了コード 2。VRM 1.0 だけ（VRM 0.x と骨の足りない VRM は止める）。
- 順は 細く（腕、腰、脚）→ 肩 → 首 → 頭。どれも頂点と骨（節点）と逆バインド行列を同じ写像で直すので、静止の姿勢の形は計算どおりになる。元の逆バインド行列が節点の静止の姿勢と一致しないモデル（手の向きを直したものなど）でも、その差は変えない。
- 腕・腰・脚: 骨ごとに、頂点を骨の軸（骨の頭から子の頭）へ重みの分だけ寄せる。軸に沿った位置は変えない。腰は spine の重みで、体の中心の縦の線へ水平に寄せ、前後は変化を半分にする。脚は足首からすねの 4 割までを元へ戻す。法線は寄せた分だけ直し、モーフの差分も同じ写像で直す。その骨のコライダーは半径と、軸に垂直な offset を同じ倍率にする（spine は半径だけ）。
- 肩: 上腕（肩の骨があれば肩）から先の骨を横へ動かす。頂点は腕の骨の重み、または胸の上の帯（上腕の高さの 0.909〜0.959 倍）で、|x| が上腕の |x| の 0.45 倍から上腕まで滑らかにつなぐ。頭の重みのある頂点は動かさない。
- 首: 頭とその子の骨を上へ動かす。頂点は頭の重みの分だけ動かし、首の筒（首の中心から水平に、首の重みの頂点の距離の中央値の 1.4 倍以内、(head - neck) の 0.6 倍まで）は首の区間（neck の高さ + (head - neck) の 0.15〜0.6）で滑らかに伸ばす。襟は動かない。
- 頭: 首の区間の中ほどの首の中心を中心に、頭とその子に全部の重みがある頂点を一様に拡縮する（首の筒の中の区間より下は、倍率を 1 から滑らかにつなぐ）。頭の下のコライダーの offset と半径、揺れ骨の当たりの半径、モーフの差分も同じ倍率にする。
- 確かめは `test/body_shape_check.py`（`test/fixtures/make_humanoid.py` の小さな人型）。

## 首の長さ（`tools/vrm/neck_len.py`）

```bash
python tools/vrm/neck_len.py in.vrm --probe                                  # 首と頭の骨の高さ
python tools/vrm/neck_len.py in.vrm out.vrm --delta 0.0075 --band 1.262 1.272
```

- `--band z0 z1`（m、VRM の座標）の区間を縦に伸ばし（`--delta` が正）、縮める（負）。z1 より上は `--delta` だけ上がる。区間の中は smoothstep でつなぐので段は付かない。区間は首の見えている所（あごの下から襟の上）にとる。
- 頭の骨とその子（髪の揺れ骨、目）の節点を動かし、逆バインド行列も同じだけ平行移動する。静止の形は変わらない。
- 頂点は、`--tube-meshes`（既定 `Body`。首と胴が 1 枚のメッシュ）では首の筒（頭の骨から水平に `--radius` 0.035 m 以内）と z1 より上だけの部品（帽子など）を動かし、肩や襟は動かさない。ほかのメッシュ（顔、髪）は全部の頂点を高さで動かす（区間より下は動かない）。
- モーフの差分は変えない。コライダーは骨の子なので骨と一緒に動く。

## primitive をまとめる(`tools/vrm/merge_prims.py`)

```bash
python tools/vrm/merge_prims.py in.vrm out.vrm --mesh Face_layers
```

同じメッシュの中で、材質、属性、モーフの数が同じ primitive を 1 個にまとめる。three.js は primitive を 1 個ずつ別の描画にするので、顔の層が 60 個に分かれていると draw call が 60 増える。頂点、UV、骨の重み、モーフの差分は連結するだけで、メッシュの番号とモーフの順は変わらないため、表情の割り当てはそのまま動く。使わなくなったデータは詰めて書く。

## UV の余白を島の縁の色で埋める(`tools/vrm/uv_pad.py`)

```bash
python tools/vrm/uv_pad.py in.vrm --mesh Face --ymin 1.18 --ymax 1.36 --probe     # 変わる画素の数だけ出す
python tools/vrm/uv_pad.py in.vrm out.vrm --mesh Face --ymin 1.18 --ymax 1.36 [--pad 16] [--debug dir]
```

テクスチャを塗り直す道具が UV の島の中だけを塗ると、島の外の余白に元の色が残る。描くときの双一次の補間とミップマップで余白の色が島の縁ににじみ、UV の継ぎ目が細い線になって見える。この道具は、どの三角形にも中心を覆われない画素のうち、島から `--pad` 画素(既定 16)以内のものを、いちばん近い覆われた画素の色にする。覆われた画素(島の中)は変えない。`--ymin`/`--ymax`(m、VRM の座標の高さ)を渡すと、その高さの三角形の近くの余白だけを埋める。画像のバイトだけを差し替えるので、頂点、骨、モーフ、揺れ骨は変わらない。
